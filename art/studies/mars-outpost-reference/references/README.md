# Reference pack

`manifest.json` is the portable public index: stable IDs, SHA-256 hashes,
dimensions, roles, selection state and discrepancies. It contains no private
filesystem locations or source filenames.

The nine original PNGs and `manifest.json` containing their actual filenames
are retained under ignored `private/`. Paths in that private manifest are
relative to this study. Copy that directory only through an authorized private
transfer when another authoring environment needs the reference bytes. Check
each received file against the public hash before using it. The public index
does not imply that a clean checkout contains the private inputs.

These user-supplied concepts guide newly authored geometry. Their redistribution
rights are unverified; they must not be published or packaged as game textures.
The original input folder and private pack are not production dependencies.
Record provenance and distribution permission separately for every newly
authored or acquired runtime asset.

No reference selection is approval of the runtime Outpost. The proposed layout
is `ref-layout`; `ref-outpost` controls the first finished district and
`ref-street` controls close-range material and scale quality.
