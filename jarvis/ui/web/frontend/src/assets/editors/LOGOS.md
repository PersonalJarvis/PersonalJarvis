# Code-editor marks

The original marks of the code editors a project folder can be opened in,
bundled so the sidebar menu renders them offline and on every OS. They are
kept apart from the tool-brand folders on purpose: those are matched against
tool names, and an editor mark must only ever label its own "Open in" item.

Every mark belongs to its owner and is used solely to identify the editor the
menu item launches (nominative use). It does not imply endorsement. If you own
a mark listed here and want it removed, open an issue and it will be taken out.
