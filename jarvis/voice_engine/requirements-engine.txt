# Installed by jarvis/realtime/local_voice_setup.py into a uv-managed CPython
# 3.12 venv under the engine home, never into the app's interpreter. Torch is
# fetched with `uv pip install --torch-backend cpu`, so speech runs on the CPU
# everywhere (plan section 4.7) and no 2 GB CUDA wheel is downloaded.

# 2026-10-01). Per-platform hashed locks are P3 work (plan section 4.10); until
# then these exact pins are the contract. `uv pip compile --torch-backend cpu`
# resolves them for Windows x64/arm64, Linux x64/arm64 (glibc 2.28+) and
# macOS 14+ on Apple Silicon. Intel Macs and older macOS have no onnxruntime
# 1.30 wheels; setup refuses there up front (unsupported_reason). Installs
# were run on Windows x64 only.
