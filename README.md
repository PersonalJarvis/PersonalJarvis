Personal Jarvis is not another chat window. It is one desktop app that pulls
everything AI can do on a computer into a single place: a multi-agent coding
workspace, persistent AI agents with their own memory, a voice assistant with
a wake word, desktop and browser control, a plugin marketplace, and every
model you already pay for — hosted, local, or your existing subscriptions.

You say what you want. Jarvis answers, does it on your computer, or hands it
to the right agent — and you watch every step.

**Free, open source, runs on your machine.** No account, no cloud of ours in
between. Windows, macOS and Linux, plus a headless server mode.

## What's inside

| | |
|---|---|
| **Agentic IDE** | Run Claude Code, Codex, OpenCode, Kimi Code, GLM, Grok Build, Antigravity, Cursor CLI and DeepSeek Harness side by side in live terminal panes — as many as your machine can hold. Brief them by voice. |
| **Jarvis Agents** | Build a team of persistent AI agents. Each one has its own chat, instructions, tools, schedule and memory, and learns from its own work. |
| **Jarvis Verse** | Watch your agents live in a 3D world: they walk to their desks, pick up work, and show what they are doing right now. |
| **Voice** | Wake word, natural live conversations, dictation into any app, and phone calls. Interrupt it like a person. |
| **Computer use** | Jarvis operates your desktop and browser itself — clicking, typing, reading the screen — with you in control. |
| **Marketplace** | 40+ one-click plugins, MCP servers, skills and command-line tools: GitHub, Google Workspace, Notion, Slack, Linear, Spotify, Home Assistant and more. |
| **Any model** | OpenAI, Anthropic, Gemini, OpenRouter, NVIDIA, Ollama and any local server — or your Claude and ChatGPT subscriptions. Mix them per task. |
| **Memory** | A local wiki Jarvis reads, writes and cites, so context survives across chats, agents and days. |
| **Routines** | Recurring work on a schedule: morning briefings, inbox sweeps, nightly reports. |
| **Appshots** | Two keys show Jarvis the window — or the exact area — you are looking at. Record clips the same way. |
| **Pets** | A small animated companion on your desktop that reacts while Jarvis listens, thinks and talks. |

## Vibe coding, multiplied

The **Agentic IDE** turns one screen into a coding floor. Open a project, split
it into panes, and give each pane its own coding agent. Every pane gets a call
sign, so you can steer them hands-free:

> *"Tell T1 to write the tests."* · *"What is T2 working on?"* · *"Send the fix plan to all panes."*

- **Every coding CLI in one place.** Use the subscriptions you already have; Jarvis
  detects what is installed and starts it in a pane with one key.
- **One brief, many agents.** Send the same task to several panes and compare
  what comes back.
- **Hands-free.** Talk to Jarvis while the agents type; it relays your brief
  to the right pane by its call sign.
- **Take over any time.** Every pane is a real terminal you can type into.

[Agentic IDE guide →](https://github.com/PersonalJarvis/PersonalJarvis/blob/main/docs/product/extend-and-automate/agentic-ide.md)

## A team of agents that keeps working

**Jarvis Agents** are long-lived specialists you create in one click — a
researcher, a release manager, a marketing writer, whatever your work needs.

- **One endless chat per agent.** Pick it up tomorrow where you left off.
- **They learn.** Agents keep private lessons from their own work and get
  better at your tasks over time.
- **They run on schedule.** Give an agent a routine and it does the work
  without being asked.
- **They hand back real output.** Files, reports and plans land in Artifacts,
  with every tool call visible.
- **Longer missions run isolated.** Coding missions work in their own git
  worktree, can split into parallel workers, and pass a review before you see
  the result.

## Talk to your computer

Pick your own wake phrase — "Hey Nova", "Jarvis", anything — and just talk.

- **Live conversations** with natural turn-taking. Ask it to open a site, check
  your calendar, or dispatch an agent mid-sentence.
- **Dictation** types what you say into any app, with a personal dictionary.
- **Phone calls** through your own number: call Jarvis, or let it call someone
  for you after you approve.
- **Local speech** works fully offline; hosted voices are optional.

## You stay in control

Every action passes a risk check — **safe, monitor, ask, or block**. Anything
that could change your system waits for your approval, and every run is
recorded so you can see exactly what happened. Keys are stored in your operating
system's credential store. Nothing leaves your machine unless you connect a service
that needs it.

[Safety and approvals →](https://github.com/PersonalJarvis/PersonalJarvis/blob/main/docs/product/privacy-safety-and-support/safety-and-approvals.md) ·

## Install

**Windows — PowerShell**

```powershell
irm https://raw.githubusercontent.com/PersonalJarvis/PersonalJarvis/main/install/install.ps1 | iex
```

**macOS and Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/PersonalJarvis/PersonalJarvis/main/install/install.sh | bash
```

The installer checks Python 3.11+ and Git, offers to install anything missing,
registers the desktop launcher and opens the app. Running it again updates an
existing installation. Language, wake phrase and models are set up inside the
app.

**Desktop downloads:** [Windows](https://github.com/PersonalJarvis/PersonalJarvis/releases/latest/download/PersonalJarvis-Setup-x64.exe) ·
[macOS (Apple Silicon)](https://github.com/PersonalJarvis/PersonalJarvis/releases/latest/download/PersonalJarvis-macOS-arm64.dmg) ·
[macOS (Intel)](https://github.com/PersonalJarvis/PersonalJarvis/releases/latest/download/PersonalJarvis-macOS-x64.dmg) ·
[Linux AppImage](https://github.com/PersonalJarvis/PersonalJarvis/releases/latest/download/PersonalJarvis-Linux-x86_64.AppImage)

> **macOS:** the disk image is not Apple-notarized yet, so the first launch
> needs **System Settings > Privacy & Security > Open Anyway** (macOS 15;
> right-click > Open works up to macOS 14). The one-line installer above needs
> no such step.

**Server:** `pip install personal-jarvis` and `jarvis serve`, then open
`http://localhost:47821` from a browser. Remote microphone access needs HTTPS.
See the [headless deployment guide](https://github.com/PersonalJarvis/PersonalJarvis/blob/main/docs/headless-vps-deployment.md).
Manual pip/pipx installs on Intel macOS and Windows ARM64 also need the
[native package index](https://github.com/PersonalJarvis/PersonalJarvis/blob/main/docs/product/start-here/install-personal-jarvis.md#install-the-isolated-pypi-package);
the installer configures it automatically.

**You need** one API key, a subscription, or a local model. A microphone helps
for voice. No GPU required.

## First steps

1. Finish the short setup in the app: language, your wake phrase (or a keyboard
   shortcut), and one model.
2. Say your wake phrase and ask for something — *"Plan a small project with me
   and ask what you need to know."*
3. Open a project folder in the **Agentic IDE**, or create your first agent.

## Works with

- **Models:** OpenAI, Anthropic Claude, Google Gemini and Vertex AI, OpenRouter, NVIDIA, Ollama and any OpenAI-compatible local server, plus your Claude Code and Codex subscriptions.
- **Coding agents:** Claude Code, Codex, OpenCode, Kimi Code, GLM, Grok Build, Antigravity, Cursor CLI and DeepSeek Harness.
- **Speech:** local Whisper, OpenAI, Gemini, Groq, Deepgram and OpenRouter for listening; Piper (local), ElevenLabs, Cartesia, Inworld, Gemini and OpenRouter voices for speaking.
